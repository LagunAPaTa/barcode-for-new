# Barcode GLPI plugin

## Compatibility

This plugin is compatible with:
- GLPI 10.0.x
- GLPI 11.0.x (including 11.0.6)
- PHP 8.1 or higher

**Version 2.8.0** adds full support for GLPI 11 while maintaining backward compatibility with GLPI 10.

## Installation

See [UPGRADE.md](UPGRADE.md) for detailed installation and upgrade instructions.

For GLPI 11 compatibility details, see [GLPI11_COMPATIBILITY.md](GLPI11_COMPATIBILITY.md).

## Usage

To use it, go in computer list, check the computers and in massive action, you have 2 possibilities : 

* print a bar code
* print a QRcode
